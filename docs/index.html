Live Transcript for Microsoft Teams

Save a Teams meeting's transcript as a text file while the meeting is still going.

What it does

  • Records every paragraph in the meeting's Transcript pane as it appears, or the live captions if transcription is off.
  • Catches up on everything said before you opened the pane, and fills in lines you missed while scrolled up.
  • Never skips silently: if a paragraph can't be read, the file says so and marks the spot.
  • Keeps a backup as you go, so nothing is lost if the meeting ends or the tab closes.
  • Saves a tidy .txt named by date, start time and meeting, e.g. 20th Nov '26, 10.23am - Weekly sync - transcript.txt.

How to use it

  1. Join the meeting in Edge or Chrome at teams.microsoft.com (the desktop app can't be read by a browser extension).
  2. Open the Transcript pane once transcription is on. A small "Recording transcript" badge appears.
  3. Click Save .txt on the badge, or in the extension's popup, at any time.

Privacy

Everything stays on your computer. Nothing is sent anywhere. Read the privacy policy.
